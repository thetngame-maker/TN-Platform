# TN Game OS 5.147.0

## Private Adventure Packing Checklist

- Adds six predefined packing checks to scheduled, non-archived Saved Adventures.
- Saves only validated completion keys in the existing owner-only plan library.
- Requires an authenticated Explorer, valid nonce, owned plan, and scheduled date for every update.
- Clears stale completion when the plan date changes and does not copy completion into duplicated plans.
- Reflects explicit updates in the private Day-of Adventure Brief without exposing packing data through sharing or calendar exports.
