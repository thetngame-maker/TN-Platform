# TN Platform Technical Specification v1.0

This directory is the normative implementation reference for TN Platform.

## Specifications

1. Platform foundation and service boundaries
2. Universal entity and relationship contracts
3. Discovery record and provider contracts
4. API and event conventions
5. Storage, versioning, provenance, and audit requirements
6. Release, testing, deployment, and compatibility rules

The machine-readable contract package in `packages/contracts` is authoritative when prose and implementation disagree. Any intentional contract change requires an ADR and semantic version update.
