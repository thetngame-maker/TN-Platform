# TN Game OS 5.2.0

## Added

- Milestone 3 Review Studio foundation.
- Visual concert review queue and focused event workspace.
- Confidence scoring and missing-data warnings.
- Platform health ribbon and queue metrics.
- Incoming-versus-existing Traveler comparison.
- Bulk publish and ignore controls.

## Changed

- TN Game OS version increased from 5.1.0 to 5.2.0.
- Concert review is now available through a destination-editor workflow rather than only the default WordPress queue table.

## Compatibility

- Traveler theme core is unchanged.
- Existing Concert Intelligence import methods remain authoritative.
- Existing queue post types and metadata remain compatible.
