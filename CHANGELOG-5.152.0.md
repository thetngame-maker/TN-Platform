# TN Game OS 5.152.0

## Adventure Prep Priority Sorting

- Adds an explicit Prep priority option to the private Saved Adventures organizer.
- Places upcoming plans needing preparation first, followed by launch-ready and non-upcoming plans.
- Orders incomplete upcoming plans by nearest date and then lowest completed-check count.
- Stores only the existing device-local organizer preference and performs no checklist or plan write.
- Uses owner-rendered card data and creates no new database record, request, notification, or public output.
