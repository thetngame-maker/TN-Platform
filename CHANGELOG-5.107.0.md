# TN Game OS 5.107.0

## Adventure Recaps v1

- Adds a private Adventure Recaps screen for completed trips and games.
- Automatically captures recap snapshots when a trip is archived or a game is completed.
- Preserves stop and checkpoint titles, imagery, earned XP, route distance, and route time.
- Connects approved community photos to the matching recap without exposing private uploads.
- Adds editable recap titles and private Explorer notes.
- Adds native device sharing with a clipboard fallback; private recap URLs are not shared.
- Links Recaps from Trips, Past Trips, and Completed Adventures.
- Clears finished active-trip route state only after the recap snapshot is saved.
- Adds responsive layouts and 44px+ actions for mobile Explorer use.
