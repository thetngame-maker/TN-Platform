# TN Game OS 5.134.0

## Upcoming Adventures Calendar Export

- Adds one calendar export for all upcoming Saved Adventures.
- Creates a separate standard VEVENT for each scheduled plan, including overnight timing.
- Includes the private plan title and complete saved stop list in the downloaded file.
- Excludes archived, unscheduled, and past adventures.
- Leaves the existing single-plan calendar export available.
- Runs entirely in the browser after an explicit click with no server write or external permission.
