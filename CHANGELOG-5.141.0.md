# TN Game OS 5.141.0

## Offline Adventure Refresh Guidance

- Recommends refreshing a complete public-stop pack seven days after its last verification.
- Flags migrated packs without verification metadata for one manual refresh.
- Keeps changed stop lists labeled “Update available” and age-only prompts labeled “Refresh recommended.”
- Adds a distinct mobile-friendly refresh state and action label to Saved Adventure cards.
- Retains the verified working pack when any refresh is partial, unsafe, interrupted, or low on storage.
- Adds no timer, background fetch, automatic update, private cache, or server-side activity tracking.
