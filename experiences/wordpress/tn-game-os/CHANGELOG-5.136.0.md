# TN Game OS 5.136.0

## Offline Adventure Pack Freshness

- Compares cached public stop URLs with each Saved Adventure's current public stop list.
- Marks a pack as needing an update when stops were added, removed, or changed.
- Preserves downloaded screens until the Explorer explicitly chooses Update or Remove.
- Calculates status inside device Cache Storage without fetching content.
- Keeps private plan details, notes, readiness, XP, profiles, photos, and writes out of the cache.
- Adds no background refresh, automatic download, sync event, or notification.
