# TN Game OS 5.115.0 — Active Adventure Resume

- Marks the private Saved Adventure currently loaded into Trips.
- Shows completed, skipped, remaining, and resolved progress on its Saved Adventure card.
- Adds one-tap Resume Adventure controls to Trips and Saved Adventures.
- Treats skipped stops as resolved so they do not reappear as the next stop.
- Computes progress from the current Explorer's existing trip metadata without background writes.
