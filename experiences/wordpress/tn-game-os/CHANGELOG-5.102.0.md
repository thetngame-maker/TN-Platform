# TN Game OS 5.102.0 — Universal Map v1

## Universal object registry

- Adds one canonical registry for all public, map-capable TN Game objects.
- Normalizes native games, Traveler activities, Top Sights, destinations, lodging, tours, rentals, transportation, and concert venues.
- Supports legacy coordinate fields, ACF map values, TN Game destination coordinates, venue coordinates, inherited coordinates, and game checkpoint starts.
- Excludes suspicious out-of-region coordinates from the public map.

## Universal Map experience

- Replaces the fixed four-filter map with filters generated from every populated collection.
- Adds instant keyword search across titles, descriptions, taxonomies, and AI profiles.
- Adds category-specific markers, XP context, clustering, directions, and Trips actions.
- Keeps the map, discovery sheet, search, filters, and app navigation optimized for approximately 390px widths.

## Map health

- Adds **TN Game OS → Universal Map** in WordPress admin.
- Reports mapped, eligible, missing, suspicious, and unavailable objects.
- Lists objects that need coordinate repairs with direct edit links.
