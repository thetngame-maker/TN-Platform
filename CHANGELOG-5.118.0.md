# TN Game OS 5.118.0 — Private-Safe Adventure Sharing

- Adds an explicit Share Plan action to Saved Adventures.
- Uses the native device share sheet with a clipboard fallback.
- Shares only the plan title, visible stop names, and public TN Game homepage.
- Excludes account IDs, plan IDs, private recap links, progress, and profile data.
- Creates no server write or public copy of the private plan.
