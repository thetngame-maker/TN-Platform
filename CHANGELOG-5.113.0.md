# TN Game OS 5.113.0 — Saved Adventure Maps

- Adds a View Map action to every private Saved Adventure.
- Resolves only the owning Explorer's requested plan and published, mapped stops.
- Draws numbered Leaflet markers and a connected route in saved itinerary order.
- Fits the Universal Map to the route without removing discovery markers, filters, search, or Nearby tools.
- Returns no plan overlay for signed-out visitors, unknown plan IDs, unpublished stops, or unmapped stops.
